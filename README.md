# UI-UX-Experiment2

## Aim:
To design a mobile app layout for a Chinese Food Shop using Canva.
## Algorithm:
Step 1: Open Canva and create mobile design.
Step 2: Set background and theme colors.
Step 3: Add logo and splash screen.
Step 4: Create home screen.
Step 5: Add food cards and categories.
Step 6: Design food detail page.
Step 7: Create cart page.
Step 8: Download final design.
